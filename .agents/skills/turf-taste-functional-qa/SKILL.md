# Turf & Taste Functional QA Skill

## Core Directives:
1. **No Route-Only Testing:** Never mark a user flow verified solely because a static URL returns HTTP 200.
2. **Interactive Progression:** Verify that buttons click, forms accept typed text, inputs validate mobile numbers/names, slot selections update prices, and steps guard prerequisites.
3. **Responsive Mobile Standards:** Test 360px, 375px, 390px, 412px, 430px viewports with zero horizontal overflow and sticky bottom bars properly placed.
4. **Resilience Testing:** Verify recovery states for offline and server errors with functional recovery actions.
