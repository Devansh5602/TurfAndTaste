# Turf & Taste Admin CMS Skill

## Core Directives:
1. **Dynamic Extensibility:** Admin can add new sections, facilities, pricing packages, and services without hardcoding 5 sports into the schema.
2. **Naming Convention:** Support system auto-naming (e.g., Box Cricket Turf 1, Box Cricket Turf 2) alongside editable custom display names.
3. **Session Operations:** Manage scheduled vs actual start/end timestamps, QR check-ins, 15-minute extensions, and ground delay compensation.
4. **RBAC:** Implement granular permission checks rather than simple role string checks.
5. **Dining Management:** Stalls, categories, menu items, dietary tags, and live table orders.
